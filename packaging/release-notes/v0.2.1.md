fastframe 0.2.1 puts colour emoji in every piece of text an egui app draws, with one line of code. Labels, buttons, text fields, tooltips, menus and an app's own text all show emoji in the platform's own style, so apps no longer need glue of their own around every place that draws text.

![Colour emoji in a text field, song rows, the sidebar and the player bar of Spotifast's demo mode](https://github.com/crmne/fastframe/releases/download/v0.2.1/emoji-everywhere.png)

Upgrade by moving the tag on every fastframe crate:

```toml
fastframe-emoji = { git = "https://github.com/crmne/fastframe", tag = "v0.2.1" }
```

## New

- **Colour emoji in every egui text.** `ctx.add_plugin(fastframe_emoji::EmojiPlugin::default())` finds the emoji in everything egui lays out in a frame and paints the platform's colour picture in place of each monochrome glyph, clipped the way the text is. Layout, wrapping, truncation, selection, copying and right-to-left text stay exactly as egui made them, because nothing changes before the text is laid out. `EmojiSetup` and `warm_up` still choose and find the fonts. A picture that is not drawn yet keeps the monochrome glyph for that frame and appears on the next repaint, text without emoji costs a quick byte scan, and a steady frame reuses what the last one prepared. Text an app lays out with `append` or `editor_job` is left to the app, so apps that already paint their own emoji keep working, and an emoji a person actually typed next to them is still coloured.

## Known limitations

- **Emoji the monochrome font does not join are one picture across their parts.** A family, for instance, spans the width egui gave its separate glyphs.
- **Keycaps are small.** The picture fits the digit's narrow glyph.
- **Text drawn outside egui needs `Emoji::render`.** The plugin sees egui's text shapes, not text already turned into meshes, drawn by a paint callback, or rotated.
- **Windows has no country flags.** Segoe UI Emoji leaves them out, so they show as letters unless the app bundles a colour font with `EmojiSetup::bundled`.
