fastframe 0.2.2 shows an app's own icon in Linux tray hosts that look icons up by name, where they showed an image-missing placeholder before.

Upgrade by moving the tag on every fastframe crate; nothing else changes:

```toml
fastframe-tray = { git = "https://github.com/crmne/fastframe", tag = "v0.2.2" }
```

## Fixed

- **The Linux tray shows the app's icon in hosts that read the icon theme.** The StatusNotifier item sent only a pixmap, and many hosts draw only what they find by icon name, so they showed a placeholder. The item now names the app's icon when the desktop has it: the Flatpak app id inside Flatpak, or the app's own id when a package installed that icon in the hicolor theme or pixmaps. A portable copy without an installed icon sends the pixmap alone, as before. By @crmne; thanks @kalligator. (#4, crmne/zapfast#310)
- **The emoji README says what the 0.2.1 notes did:** a sequence the monochrome font does not join keeps the width of its parts, with its one picture centred in it. By @crmne.

## Known limitations

- A portable copy, run without installing its icon, still depends on the host drawing the pixmap.
