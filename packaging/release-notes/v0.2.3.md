fastframe 0.2.3 makes the platform's own interface face follow the desktop's `system-ui` setting on Linux, opens an app's window on time when fontconfig is slow, keeps a log file from an app's very first run, and reads palettes linked into the themes folder.

Upgrade by moving the tag on every fastframe crate; nothing else changes:

```toml
fastframe-fonts = { git = "https://github.com/crmne/fastframe", tag = "v0.2.3" }
```

## New

- **A palette linked into the themes folder is read.** A palette that pywal, wallust or matugen writes on every wallpaper change can be linked into an app's themes folder instead of copied there. The file the link leads to is checked like any other palette: a regular file of at most 64 KiB. By @crmne; thanks @SamyEpik. (#5)

## Fixed

- **`Primary::System` follows the desktop's `system-ui` on Linux.** fastframe asked fontconfig for `system-ui:weight=…` without escaping the dash, which fontconfig reads as a family called `system`, so the answer was its default face whatever the desktop set for `system-ui`. The name is now escaped, so GNOME's Adwaita Sans or a person's own choice applies as 0.2.0 meant. `fastframe-text` had the same slip and read the rendering settings of `sans` instead of `sans-serif`. By @crmne.
- **An app's window opens even when fontconfig stalls.** The `fc-match` calls made while an app starts (the desktop's rendering settings and the interface face) now get one second, as the portal call already did. One that has not answered is stopped, and the app carries on with its fallback: the default rendering settings, or Inter with a warning in the log. By @igor-alexandrov. (#7)
- **The log file is kept from an app's first run.** `fastframe-log` now makes the folder the log file and the panic log live in when it is missing. Before, a first run logged to stderr only, and a panic on that run was not written down. By @igor-alexandrov. (#6)

## Known limitations

- **Omarchy's `system-ui` is Liberation Sans.** `Primary::System` now draws what the desktop sets, and Omarchy's default font configuration maps `system-ui` to Liberation Sans, so that is the face there until a person maps `system-ui` to another one.
- **With stock egui, an emoji sequence the monochrome font does not join still spans the width of its parts.** The apps' egui fork lays every emoji out one emoji wide; the emoji README says which egui does what.
